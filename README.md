# ☁️ Personal Cloud Storage

Полнофункциональное веб-приложение для личного облачного хранения файлов.

## Ключевые особенности
- **Покусочная (чанками) загрузка файлов (Chunked Upload):** 
  Файлы разбиваются на части по 2 МБ на клиенте и передаются последовательно. Поддерживается автосборка на сервере и фоновая загрузка без блокировки интерфейса.
- **Фоновый виджет загрузок:** 
  Загрузка файлов происходит в автономном режиме. Вы можете навигироваться по папкам, скачивать и удалять другие элементы во время загрузки.
- **Разрешение конфликтов имён:** 
  Автоматическая проверка совпадения имён перед загрузкой. При обнаружении конфликта доступен интерактивный выбор: *Заменить*, *Переименовать* или *Пропустить*.
- **Встроенный медиа-просмотрщик (File Preview):** 
  Предпросмотр изображений, видео, аудио и PDF-документов прямо в браузере с циклической навигацией (`←` / `→` или стрелки клавиатуры) и отображением лоадеров загрузки.
- **Mobile-First интерфейс:** 
  Поддержка тач-событий (долгий тап для вызова контекстного меню), адаптивный виджет загрузок и адаптированный просмотр PDF для смартфонов.
- **Серверная пагинация:** 
  Постраничная подгрузка содержимого больших директорий (по 50 элементов) предотвращает зависание UI при тысячах файлов.
- **Сохранение состояния (Persistence):** 
  Синхронизация истории навигации и незавершённых фоновых загрузок с `localStorage`. При F5/обновлении страницы путь и статусы загрузок сохраняются.
- **Безопасность и Нагрузка:** 
  JWT-авторизация в Secure HttpOnly Cookie, защита от Path Traversal, балансировка нагрузки через Nginx между несколькими FastAPI-воркерами.

## Стек технологий

### **Backend:**
- **Python 3.10+** & **FastAPI**
- **PyJWT** & **Passlib** (Bcrypt) — аутентификация и авторизация
- **Uvicorn** — ASGI-сервер

### **Frontend:**
- **React 18** (Vite)
- **Tailwind CSS** — стилизация интерфейса
- **Lucide React** — набор иконок

### **Infrastructure:**
- **Nginx** — обратный прокси-сервер и балансировщик нагрузки
- **Docker / Docker Compose** — контейнеризация
